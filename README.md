# SIMIK — The Long Summer

Next.js App Router storefront starter for SIMIK Collection 001 / Summer 2027.

## Run locally

```bash
npm install
npm run dev
```

## Current scope
- Responsive editorial storefront and six product detail routes
- Collection, about, size guide and contact pages
- Product metadata and static route generation
- Photography-pending states; no generated garment drawings represented as product photography
- Proposed fabrics, colours and prices clearly marked as provisional

## Not production-ready yet
Checkout, inventory, server-side price validation, order creation, payment gateways, shipping, customer accounts, product CMS and real sample photography are not connected. No prices or stock are treated as authoritative.
